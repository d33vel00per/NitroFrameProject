# NitroFrame

## Ваша лицензия — и ваши инструменты

NitroFrame — настольное приложение для тех, кто работает с экраном каждый день: собирает референсы, наводит порядок в материалах и держит рабочий контекст под рукой.

Это не ещё один тяжёлый комбайн, который требует привыкания. NitroFrame сделан как спокойный рабочий инструмент: открываешь, выбираешь нужное и продолжаешь работу.

![NitroFrame](../NitroFrameInstaller/Assets/reference-poster.jpg)

## Что внутри

- аккуратный рабочий интерфейс без лишнего шума;
- быстрый доступ к нужным инструментам;
- локальная установка на Windows;
- собственный installer;
- обновления через GitHub Releases.

NitroFrame рассчитан на ежедневное использование: интерфейс не спорит с содержимым и не отвлекает от задачи.

## Скачать

Актуальные сборки находятся на странице релизов:

**[Скачать последнюю версию NitroFrame](https://github.com/gothbolique/NitroFrameProject/releases/latest)**

В разделе **Assets** выберите:

- `NitroFrameInstaller.exe` — рекомендуется для первой установки;
- `NitroFrame.exe` — готовая portable-сборка, если она опубликована в релизе.

## Установка

1. Скачайте `NitroFrameInstaller.exe` из последнего релиза.
2. Запустите файл.
3. Выберите папку и завершите установку.
4. Откройте NitroFrame через созданный ярлык или из папки установки.

## Обновления

Новая версия публикуется отдельным GitHub Release с номером вида `v1.0.0`.

Откройте страницу релизов, скачайте свежий installer и установите его поверх текущей версии. Ваши локальные данные не должны зависеть от папки, куда был скачан installer.

## Совместимость

- Windows 10 и новее;
- архитектура x64;
- отдельная установка .NET не требуется для self-contained сборки.

## Примечание о проекте

Этот репозиторий используется как страница загрузки готовых сборок. Исходный код в него не публикуется.

## Лицензия

Условия использования определяются автором NitroFrame. Если для конкретной версии действуют дополнительные условия, они указаны в описании соответствующего релиза.
