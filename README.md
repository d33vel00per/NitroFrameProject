## 📌 О проекте

**NitroFrame** — десктопное приложение для Windows, которое избавляет от рутины ручного тюнинга GTA V перед каждым заходом на RP-сервер. Приложение автоматически применяет проверенные твики реестра и системы при запуске `GTA5.exe`, отслеживает процесс игры и возвращает всё в исходное состояние после закрытия.

> Никаких сторонних читов и вмешательства в память игры — только безопасные системные и реестровые оптимизации, читаемые самим Windows.

## ✨ Возможности

- 🚀 **Автотюнинг при запуске** — фоновый `ProcessWatcher` следит за `GTA5.exe` и применяет профиль твиков автоматически
- 🎮 **Поддержка RP-лаунчеров** — интеграция с Majestic и GTA5RP
- 🖥️ **Твики под вендора железа** — отдельные профили для NVIDIA/AMD и Intel/AMD CPU, определяются в мастере первого запуска
- 🛠️ **NVIDIA-инструменты** — расширенные твики питания и задержек, отключение масштабирования, форс P0-state, снятие ECC-ограничений (с двойным подтверждением для рискованных операций)
- 🎨 **Полный редактор settings.xml** — все 28 графических параметров GTA V редактируются вручную с подсказками, плюс быстрые пресеты
- 📊 **Мониторинг производительности** — использование RAM, CPU и другие метрики в реальном времени
- 🔒 **Проверка легальности** — встроенная проверка доступа к системным путям, которые могут триггерить античит RP-серверов
- 💾 **Резервное копирование настроек** — ручной и автоматический бэкап `settings.xml` с возможностью отката
- 🔑 **Система лицензий и подписок** — привязка к HWID, гибкие тарифы, вход через Telegram
- 🌐 **Приём платежей** — СБП и криптовалюта

## 📥 Установка

1. Скачай последнюю версию из раздела [Releases](../../releases)
2. Запусти установщик `NitroFrame-Setup.exe`
3. При первом запуске пройди короткий мастер настройки:
   - выбор RP-лаунчера (Majestic / GTA5RP)
   - вендор GPU (NVIDIA / AMD)
   - вендор CPU определяется автоматически
4. Готово — приложение будет само подхватывать запуск GTA V

## 💳 Тарифы

NitroFrame распространяется по подписочной модели с двумя уровнями доступа. Оплата — через СБП или криптовалюту, лицензия привязывается к HWID устройства.

> Подробности и актуальные цены — на [сайте проекта](#) или в самом приложении на странице подписки.

## 🧩 Технический стек

**Клиент**
- C# / WPF
- MVVM-архитектура

**Сервер**
- ASP.NET Core + Entity Framework Core
- PostgreSQL
- JWT-аутентификация, вход через Telegram
- Развёрнут на VPS в Docker-контейнерах

## ⚠️ Дисклеймер

NitroFrame не модифицирует память процесса игры и не даёт игровых преимуществ (aim/wallhack и т.п.) — только безопасные системные настройки. Тем не менее использование любых сторонних инструментов с RP-серверами — на усмотрение и ответственность пользователя; всегда сверяйся с правилами конкретного сервера.
