# NitroFrame v2.0.9

## Что изменилось

- Исправлена упаковка BAT-скриптов в installer.
- Исправлена ошибка `Файл не найден: advanced_power_latency.bat`.
- Исправлена работа всех NVIDIA BAT-твиков после установки.
- В публикацию включены `Assets/tools` и `Assets/scripts`.
- Добавлено резервное восстановление BAT-файлов из встроенных ресурсов.
- Добавлен `clear_memory.bat` для очистки памяти.
- Минимальная поддерживаемая версия клиента обновлена до 2.0.9.
- Старые версии ниже 2.0.9 блокируются сервером при обращении к API.
- Trial ограничен двумя днями.
- Максимальный срок новой Pro-подписки, gift-кода и ручной выдачи — 90 дней.
- Исправлена обработка Telegram-входа и команд бота.
- Пересобран self-contained installer для Windows x64.

## Проверка

- Сервер: сборка без ошибок.
- Клиент: сборка без ошибок.
- Installer: smoke test пройден.
- Payload совпадает с актуальным клиентом.

## Установка

Скачайте `NitroFrameInstaller.exe` во вкладке Assets этого релиза.
