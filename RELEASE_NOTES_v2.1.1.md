# NitroFrame v2.1.1

Починка автоматического обновления. В 2.1.0 кнопка «Обновить» не работала ни у
кого: обновление приходилось ставить руками.

## Что было сломано

- **В установку не попадал `NitroFrameUpdater.exe`.** Пакет установки содержал
  только сам клиент, поэтому нажатие «Да» в окне обновления заканчивалось
  сообщением «компонент обновления не найден».
- **Клиент искал обновлятор не там, где он лежит.** Клиент публикуется одним
  самодостаточным файлом, и путь «рядом с приложением» указывал во временную
  папку распаковки, а не в папку установки. То есть даже с вложенным файлом
  обновление не запустилось бы.

## Что исправлено

- `NitroFrameUpdater.exe` входит в установку; установщик проверяет состав пакета
  после распаковки и отказывается завершаться с неполной установкой — молча
  «успешная» установка без обновлятора больше невозможна.
- Обновлятор ищется рядом с исполняемым файлом приложения.
- Если обновлятора всё же нет, приложение предлагает открыть страницу загрузки,
  а не оставляет человека с тупиковым сообщением.
- Обновлятор уменьшен с 155 МБ до 11 МБ: из него убрана ссылка на графический
  стек, которая тянула в сборку весь WPF при полном отсутствии интерфейса.
  Единственное окно (сообщение об ошибке) показывается системными средствами.
- Сборка релиза выполняется скриптом `build-release.py` с фиксированным составом
  пакета: пропустить файл, как это случилось в 2.1.0, больше нельзя.

## Как выглядит обновление

1. Клиент проверяет `updates/latest.json` при запуске, в фоне.
2. Если версия новее — окно с описанием и вопросом «обновить?».
3. «Да» — запускается обновлятор, клиент закрывается.
4. Обновлятор закрывает клиент, скачивает установщик, сверяет SHA-256 и
   запускает его. Не сошёлся хэш — установка отменяется.
5. Установщик показывает прогресс, заменяет файлы и запускает новую версию.

## Проверка

- Цепочка проверена целиком на настоящем файле релиза: скачивание 231 МБ,
  сверка SHA-256, запуск установщика.
- Проверено, что установщик отказывается ставить неполный пакет.
- Проверено, что обновлятор отклоняет ссылку не по HTTPS, некорректный хэш и
  запуск без аргументов.
- Тесты сервера: 37 проходят.

## Установка

Скачайте `NitroFrameInstaller.exe` во вкладке Assets этого релиза.

> Пользователям 2.1.0 это обновление придётся поставить вручную: в их сборке
> обновлятора нет. Начиная с 2.1.1 обновление работает из приложения.
