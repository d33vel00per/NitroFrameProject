# NitroFrame v2.0.8

## Что изменилось

- Исправлена работа всех BAT-твиков NVIDIA в установленной версии.
- Исправлена ошибка `Файл не найден: advanced_power_latency.bat`.
- В установщик включены все необходимые BAT-скрипты:
  - расширенные твики задержек GPU;
  - отключение масштабирования;
  - отключение полноэкранной оптимизации;
  - принудительный P0-State;
  - FPS-конфиг;
  - отключение ECC;
  - снятие ограничений тактовой частоты.
- Добавлен `clear_memory.bat` для очистки памяти.
- Публикация клиента теперь всегда включает папки `Assets/tools` и `Assets/scripts`.
- Добавлено резервное восстановление BAT-файлов из встроенных ресурсов, если они отсутствуют рядом с NitroFrame.exe.
- Сохранена проверка наличия файла перед запуском — приложение не запускает несуществующий скрипт.
- Пересобран self-contained installer для Windows x64.

## Проверка

- Клиент собирается успешно.
- Установщик запускается без ошибок.
- Payload установщика содержит актуальный клиент.
- Проверена целостность клиента внутри installer.

## Установка

Скачайте `NitroFrameInstaller.exe` из Assets этого релиза и установите его поверх старой версии или в новую папку.

> Для системных твиков Windows может потребоваться запуск NitroFrame от имени администратора.
