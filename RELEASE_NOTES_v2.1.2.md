# NitroFrame v2.1.2

Обновление админской панели и мелкие правки.

## Что изменилось

- Доработана админская панель.
- В отображении подписки показывается точный остаток в днях вместо
  фиксированного «1 месяц» / «3 месяца».

## Как обновиться

Начиная с 2.1.1 обновление ставится из приложения автоматически: при запуске
NitroFrame сам предложит установить новую версию. Достаточно нажать «Да».

Если нужно поставить вручную — скачайте `NitroFrameInstaller.exe` во вкладке
Assets этого релиза.
